### Привет! 👋

Делаю небольшие, но полезные инструменты вместе с ИИ-агентами: боты, скрипты для дома и автоматизация рутины.

## Проекты

### 🎯 [VrnCartridgesBot](https://github.com/ChernyshovS/VrnCartridgesBot-showcase)
Бот для Telegram и ВКонтакте: сравнивает цены на патроны в оружейных магазинах Воронежа, приводит их к цене за один патрон и сообщает, когда нужное появилось в наличии или подешевело.
[Telegram](https://t.me/VrnCartridgesBot) · [ВКонтакте](https://vk.com/vrncartridgesbot) · [описание и скриншоты](https://github.com/ChernyshovS/VrnCartridgesBot-showcase)

### 📶 [dlink-dir825-macfilter](https://github.com/ChernyshovS/dlink-dir825-macfilter)
Блокировка устройств и белый список Wi-Fi на роутере D-Link DIR-825ACG1 — галочкой в окне или одной командой, без захода в веб-интерфейс. Работает через недокументированный API прошивки, который пришлось разобрать и описать.

### 🔋 [battery-dispenser-18650](https://github.com/ChernyshovS/battery-dispenser-18650)
Доработка 3D-модели для печати: дозатор батареек AAA и AA перестроен с сохранением всех размеров оригинала и дополнен отсеком под аккумуляторы 18650. Герметичная сетка, арки над смотровыми щелями вместо мостиков.

### 🔔 [claude-code-sound-alerts](https://github.com/ChernyshovS/claude-code-sound-alerts)
Звуковое оповещение для Claude Code: компьютер играет мелодию, когда ИИ-агент закончил работу и ждёт ответа. Ставится одним заданием для агента, включается и выключается фразой.
